# Simulation code for the shared-transmitter CV-QKD link

This repository contains the Python simulation code used for the numerical study in *System-Design Optimization of a Single-Transmitter, Single-Fiber QKD-based ITS Communication Link* by Srivastava, Ricard, Jaouën, Schiavon, and Alléaume.

The code models the shared Alice-to-Bob classical/DM-CV-QKD link, the independently provisioned return capacity, the separated-link reference, and the receiver-bandwidth, transmitter-noise, Raman-coefficient, and transport-efficiency sensitivity studies described in the paper.

## Files

- `key_rate_model.py`: trusted-receiver asymptotic key-rate calculation for binomial 64-QAM.
- `system_model.py`: complete physical model, transport constraints, noise terms, and SCR optimization.
- `run_studies.py`: main platform, spectral, distance, launch-power, and Raman studies.
- `run_sensitivities.py`: transmitter-noise and transport-efficiency sensitivity sweeps.
- `run_receiver_bandwidth_codesign.py`: receiver-bandwidth and electronic-noise co-design study.
- `run_robust_power_sweep.py`: fixed-power optimization at selected transmission distances.
- `build_figures.py`: generates the numerical figures from the simulation outputs.
- `build_frequency_layout.py`: generates the frequency-allocation schematic.
- `plot_style.py`: common plotting format used by the figure scripts.
- `verify_package.py`: checks generated results against model identities, feasibility conditions, and independent numerical evaluations.

The architecture and hardware-sharing illustrations in the manuscript are separate artwork and are not generated by these scripts.
